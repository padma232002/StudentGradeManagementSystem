# Student Grade Management System

A full-stack web-based application for managing and displaying student academic records using **Python Flask**, **HTML**, **CSS**, and **JSON**.

---

## 🔍 Features

- 🔐 Login Authentication
- ➕ Add / ✏️ Edit / ❌ Delete student details
- 📊 Auto-calculate total, grade, and pass/fail status
- 🏆 Class-wise topper display
- 🔎 Search by name, class, or hall ticket
- 📥 Export to Excel using Pandas
- 📱 User-friendly interface

---

## 💻 Technologies Used

- **Frontend:** HTML, CSS
- **Backend:** Python Flask
- **Database:** JSON
- **Tools:** GitHub, Pandas (for Excel), VS Code
